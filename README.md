# Prototype Workspace

Isolated sandbox directory for experiments, prototypes, and OpenCode sessions.

## Usage with OpenCode

To start OpenCode scoped strictly to this directory:

```bash
cd ~/Prototype
opencode
```

Or from anywhere:

```bash
opencode ~/Prototype
```

- Models available via Hack Club: Muse Spark 1.3 (`meta/muse-spark-1.3`), Qwen3 32B, Gemini 3 Flash, etc.
- Press `/model` inside OpenCode to switch between models.
